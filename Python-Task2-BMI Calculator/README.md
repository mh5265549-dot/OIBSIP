# Oasis Infobyte Python Development Internship

## Task 2: Advanced BMI Calculator & Tracker

A Python-based graphical user interface (GUI) application designed to calculate, monitor, multi-user track, and visualize historical Body Mass Index (BMI) trends over time.

### Features & Functionality
- **Interactive GUI:** Built using Python's native `tkinter` framework with clean user controls.
- **Color-Coded Feedback:** Instantly displays health classifications with intuitive color indicators.
- **Multi-User SQLite Persistence:** Automatically saves historical data mapped to specific usernames.
- **Trend Visualization:** Integrates `matplotlib` to render historical line charts tracking progress against clinical thresholds.
